# Googleフォーム アポ連携

Googleフォームの回答を、SalesNestの会社・コンタクト・商談・商品明細・予約へ登録する連携です。商談担当のGoogle Calendarが接続済みの場合は、既存の予約同期処理で予定も作成します。

## 接続

1. SalesNestの「設定 > 外部IS連携リンク」で、対象事業部と実績帰属IS担当者を指定してリンクを作成します。
2. 表示された「Googleフォーム連携」のスクリプトをコピーします。
3. 対象GoogleフォームのApps Scriptへ貼り付けます。
4. `setupSalesNestTrigger` を1回実行し、権限を許可します。
5. テスト回答を1件送信し、会社・商談・予約・Calendar同期状態を確認します。

連携URLのtokenは認証情報として扱い、公開場所へ貼らないでください。無効化する場合はSalesNestでリンクを失効します。

## 現在のフォーム項目対応

| Googleフォーム | SalesNest |
| --- | --- |
| IS担当者 | アポ獲得者・IS実績 |
| FS担当者 | 商談担当者・Calendar同期先 |
| アポ獲得日 | アポ獲得日 |
| 商談日 + 商談時間 | 商談開始日時 |
| 店舗名 | 会社名・店舗名・商談名 |
| 業種 | 業種マスタ（未登録なら自動追加） |
| 店舗住所 | 会社住所・都道府県自動判定 |
| オーナー名（カタカナ） | コンタクト |
| 店舗番号 / 携帯番号 | 会社電話 / コンタクト携帯 |
| 商材の詳細 | 主商材・追加商品明細 |
| トークの詳細 | 引継ぎメモ |
| 商談形式 | オンライン・訪問・電話 |
| 前確日 / 前確時間 / 人柄 | 引継ぎメモへ追記 |

フォームに所要時間がない場合は60分です。`所要時間`を追加した場合は30・45・60・90・120分を認識します。`ロケットナウ`はCRMの`RN`へ統一します。

## 二重登録防止

Googleフォームの回答IDと連携リンクIDから一意キーを生成します。同じ回答が再送されても、既存の会社・商談・予約情報を返し、二重作成しません。
